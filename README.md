# 📝 Notesify

A simple and modern notes-taking web app built with **React + Vite + Tailwind CSS**.

## 🚀 Live Demo
👉[https://notesify.vercel.app](https://notesify-sigma.vercel.app/)

---

## ✨ Features

- ➕ Add notes with title and description
- 🗑️ Delete notes instantly
- 🎨 Beautiful sticky-note UI
- ⚡ Fast and responsive design
- 💾 Lightweight React state management

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Lucide Icons
